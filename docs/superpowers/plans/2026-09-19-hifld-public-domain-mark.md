# Archived HIFLD Public Domain Mark Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Label the operator-confirmed archived HIFLD Open cohort with Public Domain Mark 1.0 in Portolan/STAC without assigning that status to future uploads automatically.

**Architecture:** Carry an explicit SPDX status identifier and license-link target in each typed publishing record. The inventory migration marks its HIFLD records as `CC-PDM-1.0`; the regular publishing request remains unmarked unless an operator explicitly selects the archived cohort. Render a catalog-level `LICENSE.md` status notice, but let an explicit dataset license file take precedence.

**Tech Stack:** Python 3.12, Dagster, STAC 1.1, Portolan, unittest.
